# 🎲 Digital Dice (ESP32 Project)

This project is a smart digital dice built using ESP32 and LEDs. It simulates a dice roll using an ultrasonic sensor.

## 🚀 Features
- Random dice number (1–6)
- LED display output
- Ultrasonic sensor trigger
- Fast and responsive

## 🛠️ Components Used
- ESP32
- Ultrasonic Sensor (HC-SR04)
- LEDs
- Resistors
- Breadboard & Wires

## ⚙️ How it Works
When an object is detected by the ultrasonic sensor, the ESP32 generates a random number and displays it using LEDs like a real dice.
